Turn what you ship into posts you approve.

shipnote reads your public commits each night and drafts tweets and blog posts from them. Every claim is tied to a commit, and nothing goes out until you approve it.

View on GitHub Read the setup guide

How it works

  1. Nightly dataset

    A GitHub Action collects your public commits and diffs from the last 30 days.

  2. Grounded drafts

    Each draft cites the commit SHAs it is based on. Claims without a matching commit are dropped.

  3. You approve

    You review each draft with its evidence and decide what gets posted.

Built to stay honest

Every claim traced

Each factual statement links to the commit and file it came from.

Nothing publishes itself

shipnote drafts. You approve and post. There is no auto-posting.

Fork and run it

The nightly job runs on your own GitHub account with two settings.

Setup

1. Fork github.com/abhiudayg/shipnote
2. Enable Actions in your fork
3. Set the repository variable DATASET_AUTHOR to your git name
4. Run the nightly-dataset workflow once with days = 30
